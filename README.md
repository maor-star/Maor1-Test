# 🏡 ניהול הבית

אפליקציית ווב לניהול משק בית גדול — מייבאים את **תדפיסי כרטיסי האשראי וחשבון הבנק**, המערכת שואלת על כל הוצאה **לאיזו קטגוריה לשייך אותה**, וכך יודעים **בדיוק כמה עולה להחזיק את הבית**. בנוסף מנהלים תעודות אחריות, בעלי מקצוע, רכיבי תחזוקה תקופתית ותאורה.

## יכולות

- **📊 דשבורד** — עלות אחזקת הבית (כולל/לחודש), הוצאות קבועות מנורמלות לחודש ותחזית שנתית, פילוח לפי קטגוריה, מגמת 6 חודשים, תחזוקה קרובה ואחריות שעומדת לפוג.
- **📥 ייבוא תדפיסים** — גוררים קובץ CSV מחברת האשראי/הבנק, המערכת מזהה אוטומטית את העמודות (תאריך, בית עסק, סכום), ומייבאת. **עסקאות כפולות מסוננות אוטומטית**.
- **🏷️ סיווג עסקאות** — המערכת מציגה כל הוצאה לא מסווגת ושואלת לאיזו קטגוריה לשייך; לחיצה אחת מסווגת. סימון «זכור» יוצר כלל שמסווג אוטומטית עסקאות דומות בעתיד.
- **💳 עסקאות** — כל העסקאות במקום אחד, עם סינון לפי קטגוריה/מקור/חיפוש חופשי, ועריכה/הוספה ידנית.
- **🔁 הוצאות קבועות** — חשמל, מים, ארנונה, ועד בית, אינטרנט, ביטוח, גנן, תחזוקת בריכה וכו׳ — עם נרמול לחודש ותחזית שנתית.
- **🛠️ תחזוקה ורכיבים** — לכל רכיב (מסנן מים, פילטר בריכה, מזגן, ראש המטרה...) מגדירים כל כמה זמן מחליפים, מתי הוחלף לאחרונה, ומי בעל המקצוע. המערכת מחשבת מתי צריך להחליף שוב ומתריעה. כל טיפול נרשם ביומן.
- **📜 תעודות אחריות** — פריט, יצרן, דגם, מק״ט, תאריך רכישה ואורך אחריות; חישוב תוקף אוטומטי והתראה לפני שפג.
- **👷 בעלי מקצוע** — אנשי קשר לפי תחום, טלפון, דירוג, חיוג/וואטסאפ בלחיצה, וקישור לרכיבים ולתעודות.
- **💡 תאורה ונורות** — תיעוד סוגי הנורות בכל חדר (בית נורה E27/GU10, הספק, גוון) כדי לדעת בדיוק מה לקנות בהחלפה.
- **🗂️ קטגוריות וכללים** — ניהול קטגוריות (כולל האם נספרות בעלות אחזקת הבית) וכללי סיווג אוטומטי.

הכל בעברית עם תמיכת RTL. המטבע: שקל חדש (₪).

## איך מתחילים

1. **ייבוא תדפיסים** — מורידים מאתר חברת האשראי/הבנק קובץ CSV, וגוררים אותו למסך «ייבוא תדפיסים».
2. **סיווג** — עוברים למסך «סיווג עסקאות» ומשייכים כל הוצאה לקטגוריה (מסמנים «זכור» כדי לחסוך זמן בעתיד).
3. **דשבורד** — רואים כמה באמת עולה להחזיק את הבית, לפי חודש או בסך הכל.

> טיפ: הקובץ צריך להיות בפורמט CSV. ברוב אתרי האשראי/הבנקים יש כפתור «ייצוא לאקסל/CSV». אם באקסל — «שמירה בשם» → CSV UTF‑8.

## הרצה

דרוש [Node.js](https://nodejs.org) גרסה 18 ומעלה.

```bash
npm install
npm start
```

ואז לפתוח בדפדפן: <http://localhost:3000>

לפיתוח עם ריענון אוטומטי:

```bash
npm run dev
```

## מבנה הפרויקט

```
├── server.js        שרת Express + REST API + לוגיקת ייבוא
├── db.js            הגדרת מסד הנתונים (SQLite) והסכמה
├── public/
│   ├── index.html   מבנה העמוד
│   ├── styles.css   עיצוב
│   └── app.js       לוגיקת ה‑SPA (מסכים, טפסים, ניתוח CSV)
└── data/            מסד הנתונים נשמר כאן (נוצר אוטומטית, לא ב‑git)
```

## טכנולוגיה

- **שרת:** Node.js + Express
- **מסד נתונים:** SQLite (באמצעות `better-sqlite3`) — הנתונים נשמרים מקומית בקובץ `data/home.db`
- **צד לקוח:** JavaScript מודרני ללא שלב build, עיצוב RTL, ניתוח CSV בדפדפן.

## הערות

- המערכת מיועדת למשק בית יחיד ללא מסך התחברות. אפשר להוסיף בהמשך משתמשים והרשאות.
- «עלות אחזקת הבית» מחושבת מסכום ההוצאות בקטגוריות המסומנות «נספר בעלות אחזקת הבית». משכורות/העברות מסומנות כלא‑בית ולכן אינן נכללות.
- כדי לאפס את כל הנתונים, מוחקים את התיקייה `data/`.

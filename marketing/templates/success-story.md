# Template — Success Story

**Always an approval item**, even after the other party approves. Two separate gates.

Success stories work for all three audiences with the same structure — one of the few
formats that does.

## Structure — four parts, fixed

1. **The starting constraint or number.** Where they were, and what was in the way.
2. **Two or three concrete actions taken.** What was actually done. Actions, not adjectives.
3. **The result, with timeframe, and what held over time.** A number that decayed in
   month three is a different story than one that held.
4. **One lesson useful to a non-customer.** This is what makes it content instead of a
   brochure. If a reader who will never buy from us gets nothing, the story is not finished.

## Numbers

**Real numbers only.**

Blurring is fine: "a content network at roughly 3M monthly impressions".
Invention is not. Ever.

**Never present a one-off result as typical.** If a result is above our average, the
post says so.

Any use of the ~50% figure follows the single approved wording in
`brand/messaging.md` — currently blocked pending its basis.

## Approval chain — all four, in order

1. Client's **written** approval, verified **against the contract**, not against the
   contact. Many publisher contracts prohibit name or logo use.
2. User approval of this specific post.
3. Separate logo approval if a logo appears. Text approval is not logo approval.
4. Silence is not approval. No reply within a week means no publication.

## Skeleton

```
[Starting constraint, with the number that defines it.]

[Action one.]
[Action two.]
[Action three, if there is one.]

[Result, with timeframe. What held, and for how long.]

[The lesson — stated so a non-customer can use it.]
```

## Pre-publish checklist

- [ ] Every number verified against source data
- [ ] Timeframe stated
- [ ] Durability stated — what held, over what period
- [ ] Result contextualized against our average; not presented as typical if it is not
- [ ] Lesson is genuinely usable without hiring Adnimation
- [ ] Client written approval on file, checked against contract terms
- [ ] User approval obtained
- [ ] Logo approval obtained separately, if applicable
- [ ] Screenshot, if any, screened per `brand/visual-system.md`
- [ ] `success-story` template applied unmodified

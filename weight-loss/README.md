# 💪 הדרך הקלה לרדת במשקל

אפליקציית ווב למעקב תזונה, אימונים ומשקל, עם דגש על **שינוי הרכב הגוף** (Body Recomposition) ולא רק על המספר במאזניים.
מנוע הגיימיפיקציה מעביר את הפוקוס מהשקילה אל העמידה ביעדים היומיים — חלבון, קלוריות ואימוני כוח.

## יכולות

### ללקוח
- **דשבורד אישי** — פרוגרס-ברים ליעד הקלוריות והחלבון של היום, מצב אימוני הכוח השבועי וסיכום 30 יום.
- **מד XP ורצף** — ספידומטר XP מונפש, מספר הימים הרצופים (Streak) והרמה הנוכחית.
- **דיווח יומי** — קלוריות, חלבון וצ'ק־בוקס לאימון כוח. דיווח חוזר לאותו יום *מעדכן* ולא מוסיף נקודות פעמיים.
- **שקילה שבועית** — משקל נוכחי + תמונת התקדמות (רשות). שקילה אחת לכל שבוע קלנדרי.
- **התקדמות** — גרף מגמת משקל, גרפי קלוריות וחלבון ל-30 יום ויומן דיווחים.
- **תגים** — כל התגים במערכת, מה הושג ומה עוד נעול.
- **בלוג** — מאמרים וטיפים שהמאמן מפרסם.

### למאמן (Admin)
- **דאשבורד לקוחות** — מי דיווח היום, רצף, נקודות, משקל אחרון ומספר תגים.
- **ניהול לקוחות** — יצירה, הגדרת יעדים אישיים (קלוריות, חלבון, אימונים בשבוע), איפוס סיסמה, השבתה ומחיקה.
- **כרטיס לקוח** — כל הגרפים, השקילות והתמונות של הלקוח, ומשוב אישי לכל שקילה.
- **ניהול הבלוג** — כתיבה, עריכה ומחיקה של מאמרים.

הכל בעברית עם תמיכת RTL מלאה.

## מנוע הגיימיפיקציה

| פעולה | נקודות |
| --- | --- |
| הזנת דיווח יומי | +10 XP |
| עמידה ביעד החלבון היומי | +20 XP |
| ביצוע אימון כוח | +50 XP (עם אנימציית קונפטי) |
| שקילה שבועית | +100 XP |

כל 500 XP = רמה חדשה.

**תגים:**

| תג | תנאי | בונוס |
| --- | --- | --- |
| אלוף הברזל | השלמת כל אימוני הכוח שתוכננו לשבוע | +150 XP |
| מאסטר חלבון | עמידה ביעד החלבון 7 ימים ברצף | +200 XP |
| התמדה של ברזל | רצף דיווח יומי של 14 יום | +300 XP |

הנקודות נשמרות לכל רשומה (`points_awarded`), כך שעריכת דיווח קיים מוסיפה או מורידה רק את ההפרש — אי אפשר לצבור נקודות פעמיים על אותו יום.

## הרצה

דרוש [Node.js](https://nodejs.org) גרסה 18 ומעלה.

```bash
npm install
npm start
```

ואז לפתוח בדפדפן: <http://localhost:3100>

בהרצה ראשונה נוצר משתמש מנהל:

```
admin@easyweightloss.local / admin1234
```

לפיתוח עם ריענון אוטומטי: `npm run dev`

## משתני סביבה

| משתנה | ברירת מחדל | תיאור |
| --- | --- | --- |
| `PORT` | `3100` | פורט ההאזנה |
| `DB_PATH` | `data/weightloss.db` | מיקום קובץ מסד הנתונים |
| `SESSION_SECRET` | סוד פיתוח | **חובה להגדיר בייצור** — המפתח שחותם על עוגיית ההתחברות |
| `SECURE_COOKIES` | `false` | `true` כשהאתר מוגש ב-HTTPS |
| `APP_TZ` | `Asia/Jerusalem` | אזור הזמן שלפיו נקבע "היום" לצורך רצפים ודיווחים |
| `ADMIN_EMAIL` / `ADMIN_PASSWORD` / `ADMIN_NAME` | ראה למעלה | פרטי המנהל הראשוני (נוצר רק אם אין מנהל במערכת) |

## פריסה לשרת

```bash
sudo bash deploy/setup.sh
```

הסקריפט מתקין Node.js ותלויות, מייצר `SESSION_SECRET` וסיסמת מנהל אקראיים ב-`/etc/easy-weight-loss.env`, ומגדיר שירות systemd שמרים את האפליקציה אחרי אתחול או קריסה.

## מבנה הפרויקט

```
├── server.js         שרת Express + REST API
├── db.js             סכמת מסד הנתונים (SQLite) וזריעת התגים
├── auth.js           הצפנת סיסמאות (scrypt), עוגיית סשן חתומה והרשאות
├── gamification.js   חישוב XP, רצפים, רמות ותגים
├── deploy/setup.sh   התקנה ושירות systemd
├── public/
│   ├── index.html    מסך התחברות + שלד האפליקציה
│   ├── styles.css    עיצוב RTL
│   └── app.js        לוגיקת ה-SPA (מסכים, טפסים, גרפים, אנימציות)
└── data/             מסד הנתונים ותמונות ההתקדמות (נוצר אוטומטית, לא ב-git)
```

## טכנולוגיה

- **שרת:** Node.js + Express
- **מסד נתונים:** SQLite (`better-sqlite3`)
- **אימות:** סיסמאות מוצפנות ב-scrypt (מודול `crypto` המובנה), עוגיית סשן חתומה ב-HMAC-SHA256
- **צד לקוח:** JavaScript מודרני ללא שלב build; הגרפים והאנימציות (ספידומטר XP, קונפטי, ספירת נקודות) נכתבו ב-SVG ו-CSS

## הערות אבטחה ופרטיות

- לקוח רואה ומעדכן רק את הנתונים שלו. כל מסלולי ה-API בודקים תפקיד ובעלות.
- תמונות התקדמות אינן מוגשות כקבצים סטטיים אלא דרך `/api/weigh-ins/:id/photo`, שמאפשר גישה רק לבעל התמונה או למאמן.
- בייצור חובה להגדיר `SESSION_SECRET` (סקריפט הפריסה עושה זאת אוטומטית) ולהחליף את סיסמת המנהל הראשונית.

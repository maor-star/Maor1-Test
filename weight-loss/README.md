# הדרך הקלה לירידה במשקל

אפליקציית ווב למעקב תזונה, אימונים ומשקל, עם דגש על **שינוי הרכב הגוף** (Body Recomposition) ולא רק על המספר במאזניים.
מנוע הגיימיפיקציה מעביר את הפוקוס מהשקילה אל העמידה ביעדים היומיים — חלבון, קלוריות ואימוני כוח.

## המסכים

חמישה מסכים, לפי חבילת העיצוב (`design_handoff_easy_weight_loss`):

- **דאשבורד** — הדיווח היומי (קלוריות, חלבון, אימון כוח) לצד שלושת היעדים של היום, מונה הרצף, הרמה והנקודות.
- **התקדמות** — מגמת משקל, שקילה שבועית עם היקף מותניים ותמונת התקדמות, גרפי קלוריות וחלבון ל-30 יום, טבלת שקילות ותגים.
- **הקבוצה** — הירידה המצטברת של כל החברים, רשימת החברים ואזור אישי לכל אחד.
- **המדע** — שלושת המנגנונים שהמערכת מודדת, למה לא נשקלים כל יום, והפניות לספרות.
- **מאמרים** — ספריית תוכן עם קטגוריה וזמן קריאה.

בנוסף: **הגדרות** — יעדים אישיים וסיסמה.

הכל בעברית עם תמיכת RTL מלאה.

## אין אזור מאמן

המערכת מיועדת למשתמש שמנהל את עצמו:

- **היעדים** נקבעים על ידי המשתמש עצמו במסך ההגדרות.
- **המאמרים** נזרעים עם האפליקציה (`POST_SEED` ב-`db.js`) — אין ממשק עריכה.
- **תמונות ההתקדמות** פרטיות לחלוטין: רק מי שהעלה אותן יכול לצפות בהן.
- **חברי הקבוצה** רואים זה את זה מספרי כותרת בלבד — ירידה במשקל, רצף, נקודות, שבועות ואימונים. הדיווחים היומיים, השקילות והתמונות אינם נחשפים.

## מנוע הגיימיפיקציה

| פעולה | נקודות |
| --- | --- |
| הזנת דיווח יומי | +10 XP |
| עמידה ביעד החלבון היומי | +20 XP |
| ביצוע אימון כוח | +50 XP (עם אנימציית קונפטי) |
| שקילה שבועית | +100 XP |

כל 500 XP = רמה חדשה.

**תגים:**

| תג | תנאי | בונוס |
| --- | --- | --- |
| אלוף הברזל | השלמת כל אימוני הכוח שתוכננו לשבוע | +150 XP |
| מאסטר חלבון | עמידה ביעד החלבון 7 ימים ברצף | +200 XP |
| התמדה של ברזל | רצף דיווח יומי של 14 יום | +300 XP |

הנקודות נשמרות לכל רשומה (`points_awarded`), כך שעריכת דיווח קיים מוסיפה או מורידה רק את ההפרש — אי אפשר לצבור נקודות פעמיים על אותו יום.

## הרצה

דרוש [Node.js](https://nodejs.org) גרסה 18 ומעלה.

```bash
npm install
npm start
```

ואז לפתוח בדפדפן: <http://localhost:3100>

בהרצה ראשונה נרשמים דרך מסך ההרשמה. כל מי שנרשם מצטרף לקבוצה.

לפיתוח עם ריענון אוטומטי: `npm run dev`

## משתני סביבה

| משתנה | ברירת מחדל | תיאור |
| --- | --- | --- |
| `PORT` | `3100` | פורט ההאזנה |
| `DB_PATH` | `data/weightloss.db` | מיקום קובץ מסד הנתונים |
| `SESSION_SECRET` | סוד פיתוח | **חובה להגדיר בייצור** — המפתח שחותם על עוגיית ההתחברות |
| `SECURE_COOKIES` | `false` | `true` כשהאתר מוגש ב-HTTPS |
| `APP_TZ` | `Asia/Jerusalem` | אזור הזמן שלפיו נקבע "היום" לצורך רצפים ודיווחים |

## פריסה

### AWS — stack חדש

```bash
DOMAIN=app.example.com bash deploy/aws-deploy.sh
```

יוצר CloudFormation stack עם EC2 (‏t3.micro כברירת מחדל), כתובת IP קבועה, ‏Caddy ל-HTTPS אוטומטי
ו-Session Manager לגישה לשרת בלי מפתח SSH. הסקריפט ממתין עד שהאפליקציה עונה בפועל — אם ה-stack
הצליח, האתר באוויר. בלי `DOMAIN` האתר יוגש ב-HTTP בלבד, וסיסמאות יעברו ללא הצפנה.

התבנית עצמה ב-`deploy/aws-cloudformation.yaml`. מחיקה מלאה:
`aws cloudformation delete-stack --stack-name easy-weight-loss`.

עלות משוערת: כ-8–12 דולר לחודש ל-t3.micro עם דיסק 20GB.

### שרת קיים (GCE, ‏VPS, כל Debian/Ubuntu)

```bash
sudo bash deploy/setup.sh
```

הסקריפט מתקין Node.js ותלויות, מייצר `SESSION_SECRET` אקראי ב-`/etc/easy-weight-loss.env`, ומגדיר שירות systemd שמרים את האפליקציה אחרי אתחול או קריסה.

## מבנה הפרויקט

```
├── server.js              שרת Express + REST API
├── db.js                  סכמת מסד הנתונים (SQLite), זריעת תגים ומאמרים
├── auth.js                הצפנת סיסמאות (scrypt) ועוגיית סשן חתומה
├── gamification.js        חישוב XP, רצפים, רמות ותגים
├── deploy/
│   ├── aws-cloudformation.yaml   תבנית ה-stack ל-AWS
│   ├── aws-deploy.sh             יצירת ה-stack והמתנה עד שהאתר עונה
│   └── setup.sh                  התקנה על שרת קיים
├── public/
│   ├── index.html         שלד האפליקציה ומסך ההתחברות
│   ├── design-system.css  מערכת העיצוב Industry — מקור האמת לצבע, טיפוגרפיה ומרווחים
│   ├── styles.css         שכבת האפליקציה, בנויה כולה על הטוקנים
│   └── app.js             לוגיקת ה-SPA (מסכים, טפסים, גרפים)
└── data/                  מסד הנתונים ותמונות ההתקדמות (נוצר אוטומטית, לא ב-git)
```

## מערכת העיצוב

`public/design-system.css` הוא הקובץ מחבילת ה-handoff, כמעט ללא שינוי — התוספת היחידה היא
**Heebo** כפונט העברי לצד Barlow ו-Barlow Condensed, שאין להם גליפים עבריים.
`public/styles.css` בנוי כולו על הטוקנים שלו: אין בו אף hex, שם פונט או ערך px שהטוקנים כבר נושאים.
לשינוי המראה — לערוך את המשתנים בראש `design-system.css`.

## טכנולוגיה

- **שרת:** Node.js + Express
- **מסד נתונים:** SQLite (`better-sqlite3`)
- **אימות:** סיסמאות מוצפנות ב-scrypt (מודול `crypto` המובנה), עוגיית סשן חתומה ב-HMAC-SHA256
- **צד לקוח:** JavaScript מודרני ללא שלב build; הגרפים והאנימציות (ספידומטר XP, קונפטי, ספירת נקודות) נכתבו ב-SVG ו-CSS

## הערות אבטחה ופרטיות

- כל משתמש רואה ומעדכן רק את הנתונים שלו. כל מסלולי ה-API בודקים בעלות.
- תמונות התקדמות אינן מוגשות כקבצים סטטיים אלא דרך `/api/weigh-ins/:id/photo`, שמאפשר גישה למעלה התמונה בלבד.
- מסך הקבוצה חושף מספרי כותרת בלבד; אין בו גישה לדיווחים, לשקילות או לתמונות של חבר אחר.
- בייצור חובה להגדיר `SESSION_SECRET` — סקריפט הפריסה עושה זאת אוטומטית.
